# Automotive project artwork

Created with the built-in image-generation tool. These are conceptual automotive covers, not screenshots, research outputs, or evidence of automotive project use. The originals are preserved separately; the site uses optimized WebP copies in `public/assets/projects/car-*.webp`.

Direction: charcoal classic cars, warm ivory highlights, dark workshop materials and muted vermilion accents. Every cover connects an automotive metaphor to the actual repository topic.
